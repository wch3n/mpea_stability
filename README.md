# Phase stability prediction for multicomponent alloys

This repository contains the [datasets](dataset/) and [model parameters](model_params/) used in [*A map of single-phase high-entropy alloys*](https://doi.org/10.1038/s41467-023-38423-7). The standalone calculation is in [run_stability.py](run_stability.py).

Use the [MPEA stability web app](https://mpea.alloys.dev/) to predict whether an alloy forms a single solid solution at a given temperature. The [model explanation](https://mpea.alloys.dev/about#heating) includes an interactive Fe–Co convex hull.
